# NLS source acquisition records

These files are the verified NLS source-record intake for the town-focused local late-Victorian map packs. They are deliberately separate from the local-maps directory: an acquisition record is not a publishable map layer.

Each source record was checked against the NLS map page and NLS GeoServer sheet footprint on 30 July 2026. The NLS records state CC-BY (NLS), and the exact attribution is carried in each record. The project must still retain it beside any published layer.

Before copying an acquisition record into a local-map publication intake, a curator must crop to the map neatline, independently verify at least four controls, record residual error, and approve the resulting EPSG:3857 MBTiles package. A sheet-footprint corner is useful source metadata but is not a sufficient alignment check.
