# Curation project files

`alloa-curation.template.json` is an intentionally empty source-backed template. Duplicate it for a project, replace every placeholder, remove the example feature/map objects until real records exist, then validate before seeding. It contains no historic facts, legal boundary, map imagery, or statutory records.

`../catalogues/scotland-official-sources.json` is a reviewed starting catalogue for Alloa/Scotland curation. It is not data: confirm the source's current licence, service terms, field names, and update date at each import.

## Town guide artwork style

Use the Kirriemuir and South Queensferry guide images as the locked house style for future town graphics: refined editorial watercolour with soft washes, fine restrained ink/detail, natural perspective, recognisable place cues and a premium guidebook feel.

Avoid photographic renders, photo-filtered images, flat blocky poster art, thick cartoon outlines, text inside the image, logos, watermarks, cars, bins, street clutter and generic fantasy scenery. Generated town artwork should be text-free; titles, ratings and labels belong in HTML.
