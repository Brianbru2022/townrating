# Curation project files

`alloa-curation.template.json` is an intentionally empty source-backed template. Duplicate it for a project, replace every placeholder, remove the example feature/map objects until real records exist, then validate before seeding. It contains no historic facts, legal boundary, map imagery, or statutory records.

`../catalogues/scotland-official-sources.json` is a reviewed starting catalogue for Alloa/Scotland curation. It is not data: confirm the source's current licence, service terms, field names, and update date at each import.
